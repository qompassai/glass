# Build restoration — 2026-10-09

Observation (unreviewed): as imported, this repo could not build at
all. The import that rebranded the upstream server to Glass dropped
several load-bearing pieces and half-applied dependency bumps. All of
it was repaired on primo (Rust 1.96.0, pinned in rust-toolchain.toml)
and pushed to main the same day.

## What was broken

- `libs/hbb_common/src/protos.rs` never made it into git. The build
  script generates the protobuf modules into $OUT_DIR/protos/, but
  nothing included them (E0583 + ~200 cascade errors). Restored as a
  one-line include shim.
- The rebrand renamed the package `hbbs` -> `glass` in Cargo.toml but
  not the crate targets: `src/main.rs` still does `use hbbs::`, and
  every packaging surface (debian .install files, s6 run scripts,
  systemd units) expects binaries named `hbbs`, `hbbr`,
  `glass-utils`. Restored with explicit [lib]/[[bin]] names.
- `edition` was dropped from [package], so the root crate defaulted
  to Rust 2015 and every async fn failed (E0670). Restored to 2021.
- Half-applied dependency bumps: deadpool pinned to 0.12.2 while
  database.rs spoke the 0.5-era Manager API (ported: native async
  trait methods, Metrics param, Pool::builder); base64 0.22 with one
  stray `Engine::encode` call and deprecated free functions
  everywhere else (migrated all 12 call sites in src/ to
  general_purpose::STANDARD; byte-compatible — keys generated by the
  old code still validate).
- `oqs` / `oqs-sys` were declared (vendored liboqs) but referenced by
  zero lines of code. Removed; Cargo.lock shed 135 lines. There is no
  post-quantum code in this tree today — same aspirational-dep
  pattern as the bunker audit.
- `src/mod.rs` was dead (referenced a nonexistent sled_async module;
  nothing referenced it). Removed.
- systemd unit files and FreeBSD rcd scripts still had `rustdesk-*`
  filenames while their contents and the debian manifests already
  used the glass names. Renamed (contents untouched).

## Build prerequisite worth knowing

sqlx type-checks queries against `./db_v2.sqlite3` (see .env) at
compile time. A fresh clone must create it once with the peer DDL
from Database::create_tables — documented in the README's Server
section; `nix develop` creates it automatically. The file is
gitignored build scaffolding.
